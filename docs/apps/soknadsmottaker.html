soknadsmottaker

Mottar metadata om innsendinger via REST og publiserer dem til Kafka for asynkron arkivbehandling.

Type
REST-mottakstjeneste
Kaller
innsending-api
Utdata
Kafka JSON
Kjøremiljø
Kotlin og Spring Boot

soknadsmottaker tar imot innsendte metadata, mapper dem til en Kafka-melding og publiserer meldingen. Den henter ikke filer og kommuniserer ikke med Joark.

Oppgaver

  • Mottar metadata om søknader med og uten innlogging via separate REST-endepunkter.
  • Mapper forespørsler til InnsendingTopicMsg og skjuler fødselsnumre i vanlige logger.
  • Publiserer JSON for innsendinger til riktig Kafka-topic.
  • Tilbyr også varslingsendepunkter som publiserer hendelser for message, task, draft og done.
  • Publiserer metrikker for innsendinger.

Rolle i flyten

innsending-api kaller tjenesten når brukeren sender inn. Når soknadsmottaker har publisert metadataene til Kafka, kan forespørselen fra brukeren avsluttes mens soknadsarkiverer behandler innsendingen uavhengig.

Avgrensning

Tjenesten lagrer ikke opplastede filer, beriker ikke metadata, prøver ikke Joark-kall på nytt og har ikke ansvar for endelig arkivstatus.

Tekniske detaljer

  • Kotlin og Spring Boot 4
  • Java 21 og Maven
  • OpenAPI REST-kontrakt
  • Kafka-produsent
  • Separate topic for innsendinger med og uten innlogging
  • Sikker logging av sensitive identifikatorer
  • NAIS-deploy

Integrasjoner

  • innsending-apiREST-kaller med innsendte metadata
  • soknadsarkivererKonsumerer JSON-meldingen
  • soknadarkiv-schemaEldre hendelses- og metrikkposter, ikke den primære JSON-meldingen
