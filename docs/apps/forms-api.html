forms-api

Den varige backend-tjenesten for skjemadefinisjoner, oversettelser, mottakeradresser, publiseringsoppføringer og statiske PDF-filer.

Type
Backend-tjeneste
Hovedklient
Bygger
Runtime
Kotlin og Spring Boot
Lagring
PostgreSQL

forms-api er den redigerbare kilden til skjemadata. Den støtter arbeidet med å bygge skjemaer og den nyere publiseringsmodellen. I produksjon mottar FyllUt-imaget fortsatt publisert innhold via GitHub.

Oppgaver

  • Oppretter og oppdaterer skjemadefinisjoner og skjemaoversettelser.
  • Lagrer globale oversettelser, mottaker- og arkivadresser og statiske PDF-filer.
  • Sporer publiseringer slik at FyllUt kan vise en skjemarevisjon med tilhørende oversettelser.
  • Tilbyr lese-API-er og beskytter skriveoperasjoner med Entra ID-grupper.

Rolle i flyten

Bygger bruker forms-api gjennom hele arbeidet med å lage skjemaer. FyllUt utenfor produksjon kan også hente skjemaer direkte fra tjenesten for staging. I produksjon kopierer publiseringen fortsatt utvalgt innhold til skjemautfylling-formio før FyllUt viser det.

Avgrensning

Tjenesten viser ikke skjemaer, publiserer ikke Git-commits, tar ikke imot innsendinger fra brukere og arkiverer ikke dokumenter.

Tekniske detaljer

  • Kotlin, Spring Boot 4, Java 21
  • PostgreSQL med Flyway
  • REST-API og Swagger UI
  • NAIS på GCP
  • Prometheus via Actuator
  • Entra ID-gruppebasert tilgangskontroll for skriving

Integrasjoner
