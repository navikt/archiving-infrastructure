soknadarkiv-schema

A versioned Maven artifact containing Avro records from the archiving flow, now used mainly for historical processing and metrics compatibility.

Type
Schema library
Format
Apache Avro
Distribution
Maven artifact
Runtime
None on its own

The repository name and older READMEs suggest that it owns the main submission contract. Current code tells a more specific story: the live submission message is JSON, while these Avro types remain for legacy events, metrics, and replay compatibility.

What it contains

  • The historical application archive schema.
  • Processing event records and the received, started, archived, finished, and failure event enum.
  • Metrics records and shared Avro elements.
  • Maven build configuration that generates types and publishes the package.

Role in the flow

soknadsmottaker and soknadsarkiverer depend on the artifact for shared historical types. The default version 3 submission path uses plain JSON InnsendingTopicMsg and does not need Schema Registry for its main payload.

Planning implication

Before editing a schema, identify whether the affected topic is current JSON, current Avro, or retained for migration and replay. Do not infer the live contract from the repository name alone.
