SendInn

Det innloggede webgrensesnittet for tilleggsdokumentasjon, innsendinger med bare dokumenter og gamle FyllUt-utkast som allerede inneholder SendInn-vedlegg.

SendInn er fortsatt grensesnittet for opplasting og innsending ved ettersending og innsending av bare dokumenter. Nye FyllUt-søknader håndterer nå vedlegg direkte i FyllUt.

Oppgaver

  • Åpner en eksisterende innsending med ID og viser statusen.
  • Lar brukeren laste opp, erstatte og fjerne dokumenter.
  • Fullfører innsending av tilleggsdokumentasjon og innsending av bare dokumenter.
  • Fullfører en eldre FyllUt-søknad bare hvis det lagrede utkastet allerede har vedlegg lastet opp via SendInn.
  • Henter skjemametadata fra FyllUt når den skal vise informasjon om skjemaet.

Rolle i flyten

fyllut-ettersending sender brukere hit for å laste opp filer ved digital innsending. Omdirigeringen fra FyllUt er utdatert og brukes bare for gamle utkast som allerede har SendInn-vedlegg. API-rutene i SendInns Next.js videresender forespørsler og filstrømmer til innsending-api med et TokenX-bearer-token. innsending-api eier søknadstilstanden og filene som opprettes.

Avgrensning

Den definerer ikke skjemaer, eier ikke varige søknadsdata, genererer ikke den opprinnelige PDF-en av skjemaet, publiserer ikke Kafka-meldinger og arkiverer ikke dokumenter.

Tekniske detaljer

  • Next.js og React
  • Pages Router
  • Frittstående Node-server
  • ID-porten-innlogging og TokenX-utveksling
  • Backend-proxy som strømmer filer
  • Feilrapportering med Sentry
  • Deployment-varianter for NAIS
