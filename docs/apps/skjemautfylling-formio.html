skjemautfylling-formio

Deploy-repoet som kombinerer publisert skjemainnhold med en låst versjon av FyllUt-applikasjonen.

Type

Opprettes av
Byggers publiseringsflyt
Innhold
Skjemaer, oversettelser og ressurser
Resultat
FyllUt-image for produksjon

Dette repoet pakker en valgt kodeversjon av FyllUt og publiserte skjemaer i ett produksjonsimage. Frontend-kildekoden ligger i skjemabygging-formio.

Oppgaver

  • Lagrer publisert skjema-JSON, oversettelser og tilhørende ressurser som versjonerte Git-filer.
  • Registrerer skjemabygging-formio-commiten i MONOREPO-filen.
  • Bygger fra det tilhørende FyllUt-base-imaget og kopierer skjemainnhold til faste stier i kjøremiljøet.
  • Starter deploy av det sammensatte imaget til produksjons- og utviklingsmiljøer.

Rolle i flyten

Bygger publiserer til dette repoet via GitHub API. Arbeidsflyten bygger FyllUt-imaget for produksjon. Preproduksjonsmiljøer kan hoppe over dette repoet og deploye FyllUt direkte fra skjemabygging-formio. Det forklarer noen av forskjellene mellom miljøene.

Avgrensning

Repoet tilbyr ikke API-er for å redigere skjemaer og inneholder ikke FyllUt-kildekoden. Brukerne møter ikke repoet direkte. Filene blir først en del av FyllUt-imaget.

Tekniske detaljer

  • Git-versjonerte JSON- og ressursfiler
  • Docker-image bygget på fyllut-base
  • Deploy med GitHub Actions
  • To relevante SHA-er: innhold og monorepo-kode
  • NAIS-konfigurasjon fra den låste monorepo-versjonen

Integrasjoner

  • ByggerPubliserer filer og kodeversjon
  • FyllUtLeverer base-imaget for applikasjonen
  • forms-apiLagrer redigerbare kildedata før publisering
