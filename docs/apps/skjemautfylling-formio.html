skjemautfylling-formio

The deployment repository that combines published form content with a pinned version of the FyllUt application.

Type
Content and deployment
Written by
Bygger publish flow
Contains
Forms, translations, resources
Output
Production FyllUt image

This is not another frontend codebase. It is the production packaging point for FyllUt, where a selected code version and a selected set of published forms become one image.

What it does

  • Stores published form JSON, translations, and related resources as versioned Git files.
  • Records the skjemabygging-formio commit in the MONOREPO file.
  • Builds from the matching FyllUt base image and copies form content into fixed runtime paths.
  • Triggers deployment of the combined image to production and development environments.

Role in the flow

Bygger publishes into this repository through the GitHub API. Its workflow builds the production FyllUt image. Preproduction environments can bypass this repository and deploy FyllUt directly from skjemabygging-formio, which explains some environment differences.

What it does not do

It does not provide authoring APIs or contain the FyllUt source code. It has no direct citizen interaction before its files become part of the FyllUt image.

Technical details

  • Git-versioned JSON and resource files
  • Docker image layered on fyllut-base
  • GitHub Actions deployment
  • Two relevant SHAs: content and monorepo code
  • NAIS configuration sourced from the pinned monorepo version

Connections
