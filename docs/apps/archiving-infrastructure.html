archiving-infrastructure

The local environment and black-box test suite for the complete archiving chain.

This repository is where the archive services meet as a system. It builds local images, starts dependencies, drives public and admin APIs, and verifies the resulting archive behavior.

What it does

  • Builds innsending-api, soknadsmottaker, soknadsarkiverer, and arkiv-mock images.
  • Starts the services with Kafka, PostgreSQL, and other test dependencies.
  • Runs end-to-end tests from outside the service boundaries.
  • Supports a Testcontainers mode for isolated tests and a Docker Compose mode suited to IDE debugging.
  • Runs cross-repository checks in GitHub Actions, using the pull-request branch for the changed repository and main for the others.

Role in the system

It does not run in the production flow. Its value is proving that independently deployed services and their contracts still cooperate, including retry, duplicate, failure, and restart scenarios.

Working locally

./run-end-to-end-tests.sh builds and runs the default Testcontainers setup. Add no-testcontainers to keep services in Docker Compose and replace one of them with an IDE process during debugging.
