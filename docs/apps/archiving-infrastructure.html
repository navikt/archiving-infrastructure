Systemtesting

archiving-infrastructure

Det lokale miljøet og black-box-testpakken for hele arkiveringskjeden.

Type
Testinfrastruktur
Moduser
Testcontainers og Compose
Tester
Kotlin-systemtester
CI
GitHub Actions på tvers av kodebaser

Denne kodebasen tester arkivtjenestene sammen. Den bygger lokale images, starter avhengigheter, kaller offentlige API-er og admin-API-er og sjekker resultatet av arkiveringen.

Oppgaver

  • Bygger images for innsending-api, soknadsmottaker, soknadsarkiverer og arkiv-mock.
  • Starter tjenestene med Kafka, PostgreSQL og andre testavhengigheter.
  • Kjører end-to-end-tester utenfor tjenestegrensene.
  • Støtter Testcontainers-modus for isolerte tester og Docker Compose-modus for feilsøking i IDE.
  • Kjører kontroller på tvers av kodebaser i GitHub Actions. Den bruker pull request-branchen for den endrede kodebasen og main for de andre.

Rolle i systemet

Den kjører ikke i produksjon. Den sjekker at tjenester som deployes hver for seg, håndterer hverandres forespørsler og meldinger, inkludert retries, duplikater, feil og omstarter.

Lokal utvikling

./run-end-to-end-tests.sh bygger og kjører standardoppsettet med Testcontainers. Legg til no-testcontainers for å beholde tjenestene i Docker Compose og erstatte én av dem med en prosess i IDE-en under feilsøking.

Tekniske detaljer

  • Docker Compose
  • Testcontainers
  • Kotlin- og Maven-systemtester
  • Kafka og PostgreSQL
  • Genererte OpenAPI-testklienter
  • Java 21 og Maven 3.9 via mise

Integrasjoner

  • innsending-apiLagring og orkestrering av innsendinger
  • soknadsmottakerMottak fra REST til Kafka
  • soknadsarkivererArkiveringsarbeider
  • arkiv-mockSimulering av eksterne systemer
