archiving-infrastructure

Det lokale miljøet og black-box-testpakken for hele arkiveringskjeden.

Type
Testinfrastruktur
Moduser
Testcontainers og Compose
Tester
Kotlin-systemtester
CI
GitHub Actions på tvers av repoer

Testene i dette repoet sjekker arkivtjenestene sammen. Testoppsettet bygger lokale images og starter avhengighetene. Testene kaller offentlige API-er og admin-API-er og sjekker resultatet av arkiveringen.

Oppgaver

  • Bygger images for innsending-api, soknadsmottaker, soknadsarkiverer og arkiv-mock.
  • Starter tjenestene med Kafka, PostgreSQL og andre testavhengigheter.
  • Kjører ende-til-ende-tester som svartbokstester mot tjenestene.
  • Støtter Testcontainers-modus for isolerte tester og Docker Compose-modus for feilsøking i IDE.
  • Kjører kontroller på tvers av repoer i GitHub Actions. Testoppsettet bruker pull request-branchen for repoet som er endret, og main for de andre.

Rolle i systemet

Testoppsettet kjører ikke i produksjon. Det sjekker at tjenester som deployes hver for seg, håndterer hverandres forespørsler og meldinger, inkludert nye forsøk, duplikater, feil og omstarter.

Lokal utvikling

./run-end-to-end-tests.sh bygger og kjører standardoppsettet med Testcontainers. Legg til no-testcontainers for å beholde tjenestene i Docker Compose og erstatte én av dem med en prosess i IDE-en under feilsøking.

Tekniske detaljer

  • Docker Compose
  • Testcontainers
  • Kotlin- og Maven-systemtester
  • Kafka og PostgreSQL
  • Genererte OpenAPI-testklienter
  • Java 21 og Maven 3.9 via mise

Integrasjoner
