Citizen journey

fyllut-ettersending

Helps a citizen send additional documentation after the original application, using either a paper route or a digital handoff to SendInn.

Type
Citizen frontend
Users
Applicants with an existing case
Runtime
Next.js and React
Login
ID-porten

Ettersending starts a new delivery of documents. It identifies what the documents belong to and creates the route, but SendInn handles the file upload and final digital submission.

What it does

  • Lets a user find and select the relevant form or case.
  • Collects subject and attachment descriptions needed to route additional documents.
  • Offers paper and digital delivery paths.
  • Creates an ettersending or loose-post record through innsending-api and redirects digital users to SendInn.

Role in the flow

It reads form metadata from FyllUt, then calls innsending-api with a TokenX token. For digital delivery, the returned submission ID becomes the SendInn route where the citizen uploads files and completes submission.

What it does not do

It does not render the original form, keep uploaded file bytes, or perform final submission and archiving.

Technical details

  • Next.js 16 and React 19
  • Standalone Node server
  • NAIS on GCP
  • ID-porten level 4
  • TokenX for innsending-api calls
  • Runs under /fyllut-ettersending

Connections

  • FyllUtForm list and metadata
  • innsending-apiCreates the delivery record
  • SendInnUploads and submits files
