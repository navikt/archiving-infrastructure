# System-tests
This module contains end-to-end tests. For a description of the whole archiving system,
see [the documentation](https://github.com/navikt/archiving-infrastructure/wiki).

The end-to-end tests perform various tests on the system as a whole from the outside and verify different behaviours
across the archiving flow.

For more information, see [here](https://github.com/navikt/archiving-infrastructure).
